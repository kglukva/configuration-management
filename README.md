# Эмулятор командной оболочки

Практическая работа по конфигурационному управлению.

**Вариант:** 9
**Этап:** 1 — REPL
**Язык:** Python 3

## 1. Общее описание

Проект представляет собой прототип эмулятора командной оболочки UNIX-подобной операционной системы.

На первом этапе реализуется минимальный консольный интерфейс (CLI) с поддержкой интерактивного взаимодействия с пользователем.

Согласно варианту 9 реализуются:

* приглашение к вводу с именем VFS;
* раскрытие переменных окружения реальной операционной системы;
* команда-заглушка `ls`;
* команда-заглушка `cd`;
* команда `exit`;
* обработка ошибок при вводе неизвестных команд и некорректных аргументов.

На первом этапе команды `ls` и `cd` не выполняют реальных операций с файловой системой, а выводят имя команды и переданные ей аргументы.

## 3. Функции и настройки

### CLI

После запуска программы пользователю отображается приглашение к вводу с именем VFS.

Пример:

```text
vfs> 
```

### Раскрытие переменных окружения

Парсер поддерживает переменные окружения реальной операционной системы.

Например:

```text
ls $HOME
```

Переменная `$HOME` раскрывается в значение переменной окружения macOS.

### Команда `ls`

На первом этапе является заглушкой.

Пример:

```text
vfs> ls /Users
ls ['/Users']
```

### Команда `cd`

На первом этапе является заглушкой.

Пример:

```text
vfs> cd $HOME
cd ['/Users/username']
```

### Команда `exit`

Завершает работу эмулятора.

Пример:

```text
vfs> exit
```

### Обработка ошибок

При вводе неизвестной команды программа сообщает об ошибке.

Пример:

```text
vfs> unknown
Error: unknown command: unknown
```

Также обрабатываются некорректные аргументы команд.

## 4. Запуск проекта

Для запуска проекта на macOS используется:

```bash
./run.sh
```

Также программу можно запустить напрямую:

```bash
python3 src/main.py
```

## 5. Запуск тестов

Если используется `pytest`:

```bash
python3 -m pytest
```

## 6. Пример использования

После запуска:

```text
vfs> ls
ls []

vfs> ls $HOME
ls ['/Users/username']

vfs> cd /tmp
cd ['/tmp']

vfs> unknown
Error: unknown command: unknown

vfs> exit
```
